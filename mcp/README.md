# 不動產估價報告產生器（MCP）

安裝：在 Claude 桌面版 設定 › 擴充功能（Extensions）› 進階設定 › 安裝擴充功能，選 `appraisal-report.mcpb`；或直接把檔案拖進設定視窗。安裝時選一個「案件資料夾」。

資料夾內容：
- `cases/`：每個案件一個 JSON（與網頁版「案件檔 .json」同格式，可互相匯入）
- `lvr/`：下載的實價登錄資料
- `reports/`：產出的 Word 報告書（草稿）
- `models.json`：事務所估價模型

常用說法：
- 「建一個土地案，新北市林口區○○段 101、102 地號，價格日期 115/9/30」
- 「讀 ~/Downloads/謄本 裡的 PDF，把地號、面積、權利範圍、公告現值填進案件」
- 「下載新北市實價登錄，幫我挑三件比較標的」
- 「計算並列出簽名前還缺什麼」、「產出 Word 報告」

估價師簽名不在 MCP 範圍內；報告一律標為草稿。
